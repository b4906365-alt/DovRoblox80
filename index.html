🧱 DovBlox Studio
DovScript: start x y z · speed N · jump N · gravity N · say текст · touch ЦВЕТ kill|bounce N|coins N|win N (цвета: red gold green blue purple gray). Клик по сетке ставит блок, Уровень меняет высоту, тяни по экрану — крутить камеру, щипок или колесо мыши — приблизить. В плейсах игроков Dovcoin не начисляются (coins/win дают только очки).
